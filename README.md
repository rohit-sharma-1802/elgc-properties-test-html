# ELGC Properties

Next.js website for ELGC Properties — professional property management and real estate services.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes (static)

| Route | Page |
|-------|------|
| `/` | Home |
| `/about` | About ELGC |
| `/property-list` | Property listings / Portfolio |
| `/residential-property` | Residential management |
| `/commercial-property` | Commercial assets |
| `/building-property` | Building management |
| `/property-management` | Property management services |
| `/blog` | Blog / Insights |
| `/blog/[slug]` | Blog post (e.g. market-outlook-2025) |
| `/contact` | Contact form & details |

## Brand

All copy uses **ELGC** as the brand name. Header and footer link to these routes.

## Tech

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS (custom theme: navy, gold, soft, emerald)
